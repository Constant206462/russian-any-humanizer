OpenClaw Extension

Russian Humanizer

Плагин, который заставит искусственный интеллект писать, как живой человек. Никакой «воды», «мозаик» и «в современном быстро меняющемся мире».

Установить с GitHub Как это работает?
🎯

Убийца Канцелярита

Плагин по паттернам находит ИИ-штампы, отглагольные существительные и шаблонные метафоры (ChatGPT-маркеры).

✨

Авто-Очистка

Нативный инструмент `auto_fix_slop` автоматически удаляет вводную воду и метакомментарии, сокращая текст.

📈

Анализ Ритма

Математический расчет длины предложений. Плагин укажет, если текст слишком монотонный и искусственный.
